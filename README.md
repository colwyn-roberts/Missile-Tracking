Space - Space
 * Contains scripts to automatically target enemy ships, and avoid the given coordinates of a ship.
 * Implementation of protected coordinates is up to user
 * https://www.desmos.com/calculator/n0tsux9jcc

Space - Ground
 * Allows for orbital bombardments of ground locations
 * If you are using an orbiting mod, you must ensure that coordinates are local and not global, as well as make sure you are inside of the local coordinates of the planet before launching the missile.
 * Has no object avoidance, make sure you are on the right side of the planet before launching, you will get better results the closer you are to the perpendicular line from the target location.

Coordinate Grabber
 * Scripts for a control center and small drone
 * Use keybind to automatically send coordinates from the drone to the control center, useful for Space - Ground bombardments.
